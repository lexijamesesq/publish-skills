# publish-skills

This repository is a Claude Code plugin marketplace with one plugin, `publish`. Its `pr-council` skill and its `margot` and `pr-reviewer` agents are the review cards and the voice that the pull-request reviewer Margot loads at a pinned release, so a change to them changes how every pull request she reviews is judged once it is released and pinned. The README says how the plugin is installed and released.

The maintainer's project documentation is in Notion and its work is tracked in Linear; the front matter points to both, and they are private. Nothing personal is committed here.
